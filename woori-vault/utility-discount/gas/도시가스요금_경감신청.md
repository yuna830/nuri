# 도시가스요금 경감 신청

## 신청 경로

- 주민등록표상 주소지의 도시가스사
- 읍·면·동 행정복지센터
- 지방보훈청
- 정부24
- 복지로

## 준비 서류

- 도시가스요금 경감 신청서
- 개인정보 수집·이용 및 제공 위탁 동의서
- 대상 유형에 따라 가족관계증명서, 외국인등록증, 사회복지시설 신고서 등 추가 서류

## 신청 전 확인

- 주소지 관할 도시가스사
- 도시가스 고객번호
- 계약자와 대상자의 관계
- 적용할 복지 자격

직접 신청이 어려운 경우 한국가스공사의 대신신청 전담 콜센터 053-250-3900을 확인할 수 있다.

## 신청 절차

1. 주소로 관할 도시가스사를 확인한다.
2. 고지서에서 고객번호와 계약자를 확인한다.
3. 적용받을 복지 자격을 선택한다.
4. 도시가스사, 행정복지센터, 정부24 또는 복지로에서 신청한다.
5. 신청서와 개인정보 동의서, 대상별 추가서류를 제출한다.
6. 자격 확인 후 경감 적용 결과를 확인한다.
7. 다음 고지서에서 실제 경감 여부를 확인한다.

## 대상별 추가 서류 예시

| 상황 | 추가 확인 가능 서류 |
|---|---|
| 다자녀 세대 분리 | 가족관계증명서 |
| 위탁아동 포함 | 가정위탁보호 확인서 |
| 장애 외국인 | 외국인등록증 또는 국내거소신고증 |
| 사회복지시설 | 시설 신고서 또는 설치신고필증 |

## 서비스 입력 항목 예시

| 항목 | 설명 |
|---|---|
| applicationChannel | 신청 경로 |
| gasCompany | 관할 도시가스사 |
| customerNumber | 고객번호 |
| qualificationType | 신청 자격 |
| consentFormReady | 개인정보 동의서 준비 여부 |
| additionalDocuments | 추가서류 목록 |
| applicationStatus | 신청 진행 상태 |

## 사용자 질문 예시

- 도시가스요금 경감은 어디에서 신청해?
- 복지로에서도 신청할 수 있어?
- 필요한 서류가 뭐야?
- 관할 도시가스사는 어떻게 찾아?
- 부모님 대신 신청할 수 있어?
- 신청 후 언제부터 적용돼?

## RAG 검색 키워드 및 주의사항

검색 키워드: 도시가스요금 경감 신청, 가스요금 할인 서류, 도시가스 고객번호, 행정복지센터 가스 할인, 정부24, 복지로, 대신신청.

한국가스공사는 제도를 안내하지만 실제 요금 공급과 적용 처리는 지역 도시가스사가 담당할 수 있다. 주소지 관할 회사를 반드시 확인한다.
