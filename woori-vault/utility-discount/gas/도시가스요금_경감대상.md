# 도시가스요금 경감 대상

## 제도 설명

도시가스요금 경감은 에너지 취약계층과 사회적 배려대상자의 도시가스요금 부담을 줄이는 제도다. 주민등록표상 주소지의 도시가스사를 통해 자격 확인 후 적용한다.

## 주요 대상 범주

- 장애의 정도가 심한 장애인
- 법령상 요건을 충족하는 국가유공자, 독립유공자 등
- 기초생활수급자
- 차상위계층
- 다자녀가구
- 사회복지시설

자격이 두 개 이상이면 신청 시 가장 높은 경감 한도를 적용할 수 있다. 기존 적용 자격이 변경되면 경감이 해지될 수 있으므로 관할 도시가스사에 변동 사실을 알려야 한다.

## 판정에 필요한 정보

- 복지 자격 종류
- 주민등록상 주소와 세대 구성
- 도시가스 고객번호와 계약자
- 기존 경감 적용 여부

이 문서는 자격 범주를 설명하며 최종 대상 여부를 확정하지 않는다.

## 대상별 확인 정보

| 대상 범주 | 주요 확인 정보 |
|---|---|
| 장애인 | 장애 정도와 등록 상태 |
| 국가·독립유공자 | 관련 법령상 등급과 자격 |
| 기초생활수급자 | 급여 종류와 수급 상태 |
| 차상위계층 | 차상위 자격 유효 여부 |
| 다자녀가구 | 주민등록표상 자녀·손자녀 구성 |
| 사회복지시설 | 시설 신고 여부와 도시가스 계약 |

## 경감 적용 특징

- 자격별 경감 한도가 다를 수 있다.
- 자격이 둘 이상이면 가장 높은 경감 한도를 적용하는 방식이 사용될 수 있다.
- 자격 변경이나 주소 이전 시 관할 도시가스사에 알려야 한다.
- 지역별 도시가스사가 다르므로 주소를 기준으로 신청기관을 찾는다.

## 서비스 판단 기준

### 대상 가능성 높음

- 공식 대상 범주의 유효한 자격이 확인됨
- 주민등록 주소와 도시가스 사용 장소가 일치함
- 도시가스 고객번호가 확인됨

### 확인 필요

- 계약자와 대상자가 다름
- 이사 또는 세대 분리가 있었음
- 다자녀가구의 자녀가 세대 분리 상태임
- 두 개 이상의 자격 중 어떤 기준을 적용할지 불명확함

### 대상 가능성 낮음

- 공식 경감 대상 자격이 확인되지 않음
- 해당 주소에서 도시가스를 사용하지 않음

## 서비스 입력 항목 예시

| 항목 | 설명 |
|---|---|
| address | 주민등록상 주소 |
| gasCompany | 관할 도시가스사 |
| gasCustomerNumber | 도시가스 고객번호 |
| contractHolder | 계약자 |
| welfareQualifications | 보유한 복지 자격 목록 |
| householdMembers | 세대 구성 |
| currentDiscount | 기존 경감 여부 |
| qualificationChanged | 자격 변동 여부 |

## 간단 판단 로직

1. 주소로 관할 도시가스사를 확인한다.
2. 공식 경감 대상 자격 중 하나 이상에 해당하는지 확인한다.
3. 자격 유효 상태와 가구 조건을 확인한다.
4. 고객번호, 계약자, 사용 주소를 확인한다.
5. 기존 경감과 자격 중복 여부를 확인한다.
6. 정보가 부족하면 `NEEDS_REVIEW`, 명확하면 신청 가능성을 안내한다.
7. 최종 적용과 한도는 도시가스사 확인 결과를 사용한다.

## 사용자 질문 예시

- 수급자는 도시가스요금 할인을 받을 수 있어?
- 장애인 가구 가스요금 경감이 있어?
- 다자녀가구도 대상이야?
- 자격이 두 개면 할인을 두 번 받아?
- 이사하면 가스요금 경감을 다시 신청해야 해?

## RAG 검색 키워드 및 주의사항

검색 키워드: 도시가스 복지할인, 사회적 배려대상자, 가스요금 경감 대상, 수급자 가스 할인, 장애인 도시가스, 다자녀가구 가스요금.

고정 할인액을 문서 유사도 검색으로 답하지 않는다. 계절과 자격, 사용량에 따른 실제 적용액은 관할 도시가스사에서 확인한다.
