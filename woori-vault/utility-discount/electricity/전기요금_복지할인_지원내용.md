# 전기요금 복지할인 지원 내용

## 1. 한 줄 요약

전기요금 복지할인은 장애인, 국가·독립유공자, 기초생활수급자, 차상위계층, 사회복지시설, 생명유지장치 사용 가구, 다자녀·대가족·출산가구 등의 전기요금을 정액 또는 정률 방식으로 낮춰주는 제도이다.

자격별 할인 방식과 월 한도가 다르며, 여름철에는 일부 정액할인 대상의 한도가 확대될 수 있다.

## 2. 주요 지원 방식

| 방식 | 설명 |
|---|---|
| 정액 할인 | 해당 월 전기요금에서 자격별 월 한도까지 할인 |
| 정률 할인 | 해당 월 전기요금의 일정 비율을 할인 |
| 계약종별 할인 | 사회복지시설이나 심야전력 등 계약종별 기준에 따라 할인 |

실제 할인액은 청구된 전기요금보다 클 수 없다. 월 한도가 16,000원이더라도 할인 대상 전기요금이 10,000원이면 10,000원 범위에서 적용된다.

## 3. 주택용 주요 할인 내용

| 대상 범주 | 일반적인 지원 방식 | 월 할인 한도 또는 비율 |
|---|---|---|
| 장애인 | 정액 할인 | 월 16,000원 한도, 여름철 월 20,000원 한도 |
| 국가유공자·5·18민주유공자·독립유공자 | 정액 할인 | 월 16,000원 한도, 여름철 월 20,000원 한도 |
| 기초생활수급자 생계·의료급여 | 정액 할인 | 월 16,000원 한도, 여름철 월 20,000원 한도 |
| 기초생활수급자 주거·교육급여 | 정액 할인 | 월 10,000원 한도, 여름철 월 12,000원 한도 |
| 차상위계층 | 정액 할인 | 월 8,000원 한도, 여름철 월 10,000원 한도 |
| 다자녀·대가족·출산가구 | 정률 할인 | 월 전기요금 30%, 월 16,000원 한도 |
| 생명유지장치 사용 가구 | 정률 할인 | 주택용 전기요금 30% |
| 사회복지시설 | 정률 또는 계약종별 할인 | 해당 계약종별 기준 적용 |

위 표는 대표적인 주택용 기준이다. 장애 정도, 유공자 등급, 급여 종류, 계약종별 등 세부 요건을 충족해야 한다.

## 4. 여름철 할인

여름철 냉방비 부담을 줄이기 위해 일부 정액할인의 월 한도가 일반 기간보다 높게 적용된다.

- 장애인, 관련 유공자, 생계·의료급여 수급자: 일반 월 16,000원에서 여름철 월 20,000원 한도
- 주거·교육급여 수급자: 일반 월 10,000원에서 여름철 월 12,000원 한도
- 차상위계층: 일반 월 8,000원에서 여름철 월 10,000원 한도

여름철의 정확한 적용 월과 해당 연도 특별지원 여부는 한전ON 또는 고객센터 123에서 확인한다.

## 5. 실제 할인액이 달라지는 이유

- 복지 자격 종류가 다름
- 생계·의료·주거·교육급여별 한도가 다름
- 주택용, 일반용, 심야전력 등 계약종별이 다름
- 해당 월 전기사용량과 청구액이 다름
- 여름철 확대 한도 적용 여부가 다름
- 기존 할인 또는 다른 요금제 적용 여부가 다름
- 아파트의 개별계약·종합계약 방식이 다름

따라서 나이 또는 수급 여부 하나만으로 실제 할인액을 계산하면 안 된다.

## 6. 에너지바우처와의 관계

에너지바우처와 전기요금 복지할인은 서로 다른 제도이다.

- 에너지바우처: 선정된 에너지 취약계층에게 연간 이용권 금액을 지원
- 전기요금 복지할인: 한국전력의 자격별 요금 할인 적용

두 제도의 동시 이용 가능 여부와 고지서 적용 순서는 가구의 자격, 에너지바우처 이용 방식, 해당 연도 지침에 따라 확인해야 한다. RAG가 자동으로 중복 가능하다고 확정하지 않는다.

## 7. 청구서 확인 방법

1. 전기요금 청구서에서 할인 전 전기요금을 확인한다.
2. `복지할인`, `대가족요금`, `다자녀할인` 등 할인 항목을 확인한다.
3. 할인금액과 할인 후 청구액을 확인한다.
4. 예상한 할인이 없으면 고객번호를 준비해 한전 고객센터 123에 문의한다.
5. 이사나 자격 변경이 있었다면 변경 신청 여부를 확인한다.

## 8. 서비스 판단 기준

### 할인액 계산 가능

- 복지 자격과 급여 종류가 확인됨
- 전기 고객번호와 계약종별이 확인됨
- 해당 월 청구 전기요금이 확인됨
- 여름철 적용 여부와 기존 할인이 확인됨

### 추가 확인 필요

- 수급자이지만 급여 종류를 모름
- 고객번호나 계약종별을 모름
- 아파트 관리비로 전기요금을 납부함
- 에너지바우처 요금 차감을 함께 이용함
- 두 개 이상의 할인 자격이 있음

## 9. 서비스 입력 항목 예시

| 항목 | 설명 |
|---|---|
| welfareType | 복지할인 자격 종류 |
| benefitType | 생계·의료·주거·교육급여 구분 |
| customerNumber | 한국전력 고객번호 |
| contractType | 주택용·일반용·심야전력 등 계약종별 |
| monthlyElectricityCharge | 해당 월 할인 전 전기요금 |
| billingMonth | 청구 월 |
| summerRateApplied | 여름철 확대 한도 적용 여부 |
| currentDiscounts | 현재 적용 중인 할인 목록 |
| energyVoucherUsed | 에너지바우처 전기요금 차감 여부 |
| apartmentBillingType | 아파트 전기요금 계약·부과 방식 |

## 10. 간단 계산 로직

1. 자격과 급여 종류로 할인 방식과 최대 한도를 조회한다.
2. 계약종별이 해당 할인 대상인지 확인한다.
3. 청구 월이 여름철 확대 적용 기간인지 확인한다.
4. 정액 할인은 `할인 대상 전기요금`과 `월 한도` 중 작은 금액으로 계산한다.
5. 정률 할인은 할인 대상 전기요금에 비율을 적용한 뒤 월 한도를 확인한다.
6. 기존 할인과 중복·우선 적용 규칙을 확인한다.
7. 계산 결과는 예상액으로 표시하고 실제 고지서 또는 한전 조회 결과를 최종값으로 사용한다.

## 11. 사용자 질문 예시

- 전기요금은 얼마나 할인돼?
- 수급자는 한 달에 얼마까지 감면돼?
- 여름에는 할인 금액이 더 커져?
- 차상위계층 전기요금 할인 한도는 얼마야?
- 다자녀가구는 몇 퍼센트 할인돼?
- 에너지바우처와 전기요금 할인을 같이 받을 수 있어?
- 이번 달 고지서에 복지할인이 왜 안 보여?

## 12. 관련 문서 및 RAG 검색 키워드

관련 문서: 전기요금 복지할인 대상, 전기요금 복지할인 신청 방법, 에너지바우처 지원 내용.

검색 키워드: 전기요금 복지할인 금액, 한전 할인 한도, 수급자 전기요금 감면, 여름철 전기 할인, 장애인 전기요금, 차상위 전기요금, 다자녀 30% 할인, 생명유지장치 전기요금, 에너지바우처 중복.

## 13. 주의사항 및 출처 메모

이 문서는 전기요금 할인 구조와 대표 한도를 설명하기 위한 RAG 자료이다. 실제 할인 대상, 월 한도, 적용 월, 중복 규칙은 한국전력의 최신 약관과 고객별 계약정보에 따라 달라질 수 있다.

최종 할인액은 한전ON 또는 한국전력 고객센터 123에서 고객번호를 기준으로 확인한다. RAG 검색 결과만으로 고지서 금액을 확정하지 않는다.
