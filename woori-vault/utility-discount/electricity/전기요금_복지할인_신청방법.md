# 전기요금 복지할인 신청 방법

## 신청 전 준비

- 전기요금 고객번호
- 신청자와 계약자의 관계
- 복지 자격을 확인할 수 있는 정보
- 필요한 경우 주민등록등본, 전기요금 고지서 등 증빙자료

## 신청 및 확인 경로

- 한국전력 고객센터 123
- 한전ON 등 한국전력의 공식 비대면 채널
- 관할 행정복지센터 또는 자격별 연계 신청기관

전기사용 계약자와 복지 대상자가 다르거나 이사한 경우 추가 확인이 필요할 수 있다. 할인액과 적용 시작 시점은 고객번호를 기준으로 한국전력에 확인한다.

## 응답 시 주의

RAG는 신청 경로와 준비사항을 설명한다. 실제 할인 가능 여부와 금액은 서버의 자격 규칙 및 한국전력 확인 결과를 사용한다.

## 신청 절차

1. 본인의 복지 자격 종류를 확인한다.
2. 전기요금 고지서에서 고객번호와 계약자를 확인한다.
3. 한국전력 고객센터 123, 한전ON 또는 연계기관을 통해 신청한다.
4. 필요한 동의와 증빙자료를 제출한다.
5. 접수 결과와 할인 적용 시작일을 확인한다.
6. 다음 고지서에서 할인 적용 여부를 확인한다.

## 상황별 추가 확인

| 상황 | 확인사항 |
|---|---|
| 계약자와 대상자가 다름 | 가족관계 또는 실거주 확인 필요 여부 |
| 아파트 관리비 납부 | 관리사무소 또는 한전 처리 방식 |
| 이사함 | 새 고객번호로 재신청 또는 변경 필요 여부 |
| 이미 다른 할인 적용 | 중복 적용 또는 우선 적용 여부 |
| 시설 신청 | 시설 신고서와 계약종별 확인 |

## 서비스 입력 항목 예시

| 항목 | 설명 |
|---|---|
| applicationChannel | 123·한전ON·행정복지센터 등 |
| customerNumber | 전기 고객번호 |
| applicantIsHolder | 신청자와 계약자 일치 여부 |
| apartmentBilling | 관리비 고지 여부 |
| movedRecently | 최근 이사 여부 |
| evidenceReady | 증빙자료 준비 여부 |
| applicationStatus | 신청 상태 |

## 신청 상태 안내

- `NOT_APPLIED`: 미신청
- `DOCUMENT_REQUIRED`: 서류 보완 필요
- `APPLIED`: 접수 완료
- `UNDER_REVIEW`: 확인 중
- `APPLIED_DISCOUNT`: 할인 적용 확인
- `NEEDS_REVIEW`: 계약정보 또는 자격 추가 확인 필요

## 사용자 질문 예시

- 전기요금 복지할인은 어디서 신청해?
- 한전 고객번호는 어디에 있어?
- 한전ON으로 신청할 수 있어?
- 아파트 관리비로 내면 어떻게 신청해?
- 이사하면 다시 신청해야 해?
- 신청했는데 언제부터 할인돼?

## RAG 검색 키워드 및 주의사항

검색 키워드: 전기요금 할인 신청, 한전 123, 한전ON, 고객번호, 전기 계약자, 관리비 전기요금, 복지할인 재신청.

신청 완료와 실제 고지서 적용은 다를 수 있다. 적용 여부는 다음 고지서 또는 한국전력 조회로 확인한다.
