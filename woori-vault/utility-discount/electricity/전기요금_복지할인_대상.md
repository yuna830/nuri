# 전기요금 복지할인 대상

## 제도 설명

한국전력의 전기요금 복지할인은 사회적 배려가 필요한 가구와 시설의 전기요금 부담을 줄이는 제도다. 자격별 할인 한도와 적용 방식은 계약종별, 계절, 가구 특성에 따라 다를 수 있다.

## 주요 대상 범주

- 장애인
- 국가유공자와 독립유공자
- 기초생활수급자
- 차상위계층
- 사회복지시설
- 생명유지장치 사용 가구
- 다자녀, 대가족, 출산가구 등 한전이 정한 가구 요건

개인의 자격을 RAG 문서만으로 확정하지 않는다. 서버 규칙에서 복지 자격, 주민등록상 가구 구성, 전기사용 계약정보와 기존 할인 여부를 확인한 뒤 결과를 제시해야 한다.

## 확인할 정보

- 복지 자격 종류
- 전기요금 고객번호와 계약자
- 주민등록상 주소와 가구 구성
- 사회복지시설 여부
- 생명유지장치 사용 여부
- 기존 복지할인 적용 여부

## 대상별 확인 방향

| 대상 범주 | 주요 확인 정보 |
|---|---|
| 기초생활수급자 | 급여 종류와 수급 상태 |
| 차상위계층 | 차상위 자격과 유효기간 |
| 장애인 | 등록장애 여부와 장애 정도 |
| 국가·독립유공자 | 법령상 자격과 증서 정보 |
| 사회복지시설 | 시설 신고·인가 여부와 전기사용 계약 |
| 생명유지장치 가구 | 장치 종류, 사용 확인, 주거용 계약 여부 |
| 다자녀·대가족·출산가구 | 주민등록상 가구 구성과 자녀 정보 |

## 제도 이용 목적

- 취약계층의 필수 전력 사용 부담 완화
- 냉난방기와 의료기기 사용 가구 보호
- 사회복지시설의 운영비 부담 완화
- 다자녀·대가족·출산가구 지원

## 서비스 판단 기준

### 대상 가능성 높음

- 유효한 복지 자격과 전기 고객번호가 확인됨
- 대상자 주소와 전기사용 장소가 일치함
- 생명유지장치 또는 가구 특성이 공식 범주에 해당함

### 확인 필요

- 전기 계약자가 대상자와 다름
- 공동주택 관리비로 전기요금을 납부함
- 복지 자격은 있으나 이미 할인 적용 중인지 모름
- 이사 후 고객번호 변경 처리가 되지 않음

### 대상 가능성 낮음

- 공식 할인 범주에 해당하는 자격이 확인되지 않음
- 해당 전기사용 장소에 이미 동일 할인이 적용됨

## 서비스 입력 항목 예시

| 항목 | 설명 |
|---|---|
| welfareType | 복지 자격 종류 |
| qualificationActive | 자격 유효 여부 |
| kepcoCustomerNumber | 한전 고객번호 |
| contractHolder | 전기사용 계약자 |
| serviceAddress | 전기사용 장소 |
| householdMembers | 가구 구성 |
| lifeSupportDevice | 생명유지장치 사용 여부 |
| currentDiscount | 현재 할인 적용 여부 |

## 간단 판단 로직

1. 공식 복지할인 범주에 해당하는 자격이 있는지 확인한다.
2. 자격이 현재 유효한지 확인한다.
3. 전기 고객번호, 계약자, 사용 장소를 확인한다.
4. 가구 구성이나 생명유지장치 등 추가 조건을 확인한다.
5. 기존 할인 적용 여부와 중복 가능성을 확인한다.
6. 정보가 모두 확인되면 신청 가능성을 안내하고, 부족하면 `NEEDS_REVIEW`로 분류한다.
7. 할인액과 최종 적용 여부는 한국전력 확인 결과를 사용한다.

## 사용자 질문 예시

- 기초생활수급자는 전기요금 할인을 받을 수 있어?
- 장애인 전기요금 할인 대상이야?
- 산소발생기를 사용하면 할인돼?
- 다자녀가구도 전기요금 감면이 있어?
- 부모님 명의가 아니어도 신청할 수 있어?

## 관련 문서 및 RAG 검색 키워드

관련 문서: 전기요금 복지할인 신청 방법, 에너지바우처, 기초생활보장제도, 장애인복지서비스.

검색 키워드: 한전 복지할인, 전기요금 감면 대상, 수급자 전기 할인, 장애인 전기요금, 생명유지장치 할인, 다자녀 전기요금, 사회복지시설 전기 할인.

## 주의사항

대상 범주마다 할인액과 한도, 계절별 적용 방식이 다르다. RAG가 금액을 추정하지 않고 한국전력의 고객번호 기준 조회 결과를 우선한다.
