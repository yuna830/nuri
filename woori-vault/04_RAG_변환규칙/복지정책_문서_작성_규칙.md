
## 사용 목적

`woori-vault/복지정책/` 폴더에 보관하는 복지정책 Markdown 문서를 일관된 형식으로 작성하여 RAG 검색 품질을 높이기 위한 규칙을 정리한다.

이 문서는 API에서 자동으로 수집하는 데이터가 아니라, 직접 조사하고 작성하는 수동 정책 문서에 적용하는 작성 기준이다.

## 임베딩 방식

`복지정책/` 폴더의 Markdown 문서는 `embed_welfare_docs.py` 스크립트를 통해 Qdrant에 임베딩된다.

```txt
ai_backend/embed_welfare_docs.py
↓
woori-vault/복지정책/*.md 전체 또는 지정 파일
↓
/api/rag-documents/embed-document 호출
↓
Qdrant 저장
```

따라서 이 폴더의 문서는 작성 형식이 RAG 검색 품질에 직접 영향을 준다.

## 파일명 규칙

파일명은 정책 또는 서비스 이름을 그대로 사용한다.

```txt
기초연금.md
노인맞춤돌봄서비스.md
장애인연금.md
```

파일명에 공백, 특수문자, 영문을 혼용하지 않는다.

허브노트나 인덱스 문서는 파일명 뒤에 `_허브노트` 또는 `INDEX`를 붙인다.

```txt
노인복지서비스_허브노트.md
INDEX(전체 허브).md
```

## frontmatter 기준

모든 복지정책 문서는 상단에 아래 frontmatter를 포함한다.

```yaml
---
title: "정책명"
category: "복지정책"
target: "지원 대상 요약"
aliases:
  - "다른 이름 1"
  - "다른 이름 2"
tags:
  - "복지정책"
  - "관련 태그"
source:
  - name: "출처 기관명"
    note: "문서 제목 또는 출처 설명"
    url: "출처 URL"
updated: "YYYY-MM-DD"
---
```

## frontmatter 필드별 작성 기준

### title

정책 또는 서비스의 공식 명칭을 그대로 작성한다.

```yaml
title: "기초연금"
```

### category

복지정책 문서는 항상 아래 값으로 고정한다.

```yaml
category: "복지정책"
```

### target

지원 대상을 한 줄로 요약한다.

```yaml
target: "만 65세 이상 어르신"
target: "돌봄이 필요한 만 65세 이상 취약 어르신"
```

### aliases

사용자가 이 정책을 다른 이름으로 검색할 수 있는 경우 작성한다.

RAG 검색에서 다양한 표현으로 찾을 수 있도록 별칭을 최대한 포함한다.

```yaml
aliases:
  - "노인 맞춤 돌봄 서비스"
  - "독거노인 돌봄"
  - "어르신 돌봄서비스"
```

별칭이 없거나 공식 명칭이 유일하게 쓰이는 경우 생략할 수 있다.

### tags

복지정책 태그와 관련 키워드를 포함한다.

첫 번째 태그는 항상 `복지정책`으로 시작한다.

```yaml
tags:
  - "복지정책"
  - "노인복지"
  - "기초연금"
  - "소득인정액"
  - "현금지원"
```

사용자가 실제로 검색할 만한 키워드를 포함한다.

### source

출처는 공식 정부 기관 또는 법령 문서를 기준으로 작성한다.

```yaml
source:
  - name: "보건복지부"
    note: "2026년 기초연금 선정기준액 및 기준연금액"
    url: "https://..."
  - name: "복지로"
    note: "기초연금 서비스 안내"
    url: "https://..."
```

출처 URL에 실제 인증키나 개인정보가 포함되지 않도록 한다.

### updated

문서를 마지막으로 확인하거나 수정한 날짜를 작성한다.

```yaml
updated: "2026-06-21"
```

정책 내용이 변경되면 반드시 갱신한다.

## 본문 구성 기준

복지정책 문서의 본문은 아래 순서로 구성한다.

```md
# 정책명

## 1. 한 줄 요약

## 2. 지원 대상

## 3. 지원 내용

## 4. 선정 기준 (해당하는 경우)

## 5. 신청 방법

## 6. 신청 시기 (해당하는 경우)

## 7. 지원 금액 또는 지원 수준 (해당하는 경우)

## 8. 문의처

## 9. 주의사항 (해당하는 경우)
```

모든 섹션이 필수는 아니며, 해당하지 않는 항목은 생략할 수 있다.

## 섹션별 작성 기준

### 한 줄 요약

정책의 핵심을 한 문장으로 설명한다.

사용자가 이 정책이 무엇인지 바로 이해할 수 있도록 쓴다.

```md
## 1. 한 줄 요약

기초연금은 만 65세 이상 어르신 중 소득인정액이 선정기준액 이하인 사람에게 매월 연금을 지급하여 노후 생활 안정을 지원하는 제도이다.
```

### 지원 대상

지원 대상 조건을 목록 형태로 명확하게 작성한다.

```md
## 2. 지원 대상

- 만 65세 이상
- 대한민국 국적 보유
- 국내 거주
- 가구의 소득인정액이 선정기준액 이하
```

제외 대상이 있으면 함께 작성한다.

### 지원 내용

실제로 어떤 지원이 이루어지는지 구체적으로 작성한다.

금액이 있으면 연도 기준을 함께 명시한다.

```md
## 3. 지원 내용

2026년 기준 단독가구 최대 월 342,510원, 부부가구 최대 월 548,000원을 지급한다.
```

### 신청 방법

신청 장소, 신청 방법, 필요 서류를 포함한다.

```md
## 5. 신청 방법

- 신청 장소: 주소지 관할 읍·면·동 주민센터 또는 국민연금공단 지사
- 신청 방법: 방문 신청 또는 복지로(www.bokjiro.go.kr) 온라인 신청
- 필요 서류: 신청서, 신분증, 통장 사본
```

### 문의처

공식 문의처를 작성한다.

```md
## 8. 문의처

- 보건복지상담센터: 129
- 국민연금공단: 1355
- 복지로: www.bokjiro.go.kr
```

## RAG 검색 품질을 위한 작성 기준

사용자가 실제로 질문할 만한 표현을 자연스럽게 포함한다.

예시 질문:

```txt
기초연금 받을 수 있어?
나이 65세인데 연금 받을 수 있나요?
독거노인 지원 어떤 게 있어?
노인 돌봄 서비스 신청하려면 어떻게 해?
장애인연금 신청 방법 알려줘
복지 혜택 뭐가 있어?
```

따라서 아래 표현이 본문에 자연스럽게 포함되도록 작성한다.

```txt
지원 대상
신청 방법
받을 수 있는 사람
조건
금액
신청 장소
문의처
```

## 금액·기준 작성 기준

금액이나 선정 기준은 반드시 연도를 함께 명시한다.

```txt
2026년 기준 단독가구 선정기준액: 월 2,130,000원
```

연도가 바뀌면 updated 필드와 본문 내용을 함께 갱신한다.

## 업데이트 기준

아래 상황에서 문서를 갱신한다.

```txt
정책 내용이 변경된 경우
금액 또는 선정 기준이 바뀐 경우
신청 방법이 변경된 경우
출처 URL이 변경된 경우
오류가 발견된 경우
```

갱신 시 frontmatter의 `updated` 값을 반드시 수정한다.

## 작성하지 않는 정보

아래 정보는 복지정책 문서에 포함하지 않는다.

```txt
개인정보 원문
실제 수급자 사례 원문
API 인증키
서버 환경변수
내부 DB ID
수집 로그
테스트 URL 전체
RAG와 무관한 시스템 정보
```

## 허브노트 작성 기준

여러 정책을 묶어 안내하는 허브노트는 개별 정책 문서를 요약하고 연결하는 역할을 한다.

```md
# 노인복지서비스 허브노트

## 개요
노인복지서비스 관련 주요 제도를 정리한 허브 문서다.

## 관련 문서
- [[기초연금]]
- [[노인맞춤돌봄서비스]]
- [[장기요양보험]]
```

허브노트 자체에 상세 내용을 중복 작성하지 않는다.

## 임베딩 제외 기준

아래 조건에 해당하면 임베딩 대상에서 제외하거나 내용을 보완한다.

```txt
한 줄 요약이 없는 경우
지원 대상이 불분명한 경우
내용이 5줄 미만으로 너무 짧은 경우
출처가 없는 경우
updated가 2년 이상 지난 경우
```

## embed_welfare_docs.py 사용 기준

서버가 실행 중인 상태에서 아래 명령으로 임베딩한다.

```bash
# 전체 임베딩
python embed_welfare_docs.py

# 특정 파일만
python embed_welfare_docs.py --file 기초연금.md

# 기존 삭제 후 재임베딩
python embed_welfare_docs.py --delete
```

문서 내용이 변경된 경우 `--delete` 옵션으로 재임베딩한다.

## 최종 정리

복지정책 문서는 사용자가 복지 혜택을 질문했을 때 RAG가 정확하고 유용한 답변을 할 수 있도록 작성하는 것이 목적이다.

frontmatter의 `title`, `target`, `aliases`, `tags`는 검색 매칭에 직접 영향을 주므로 충실하게 작성한다.

본문은 한 줄 요약 → 지원 대상 → 지원 내용 → 신청 방법 → 문의처 순서로 구성하며, 금액과 기준은 반드시 연도를 명시한다.

정책 내용이 바뀌면 `updated` 필드와 본문을 함께 갱신하고 재임베딩한다.
