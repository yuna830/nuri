# 에너지바우처 신청 방법

## 신청 기간

2026년도 신청 기간은 2026년 6월 15일부터 12월 31일까지다.

## 신청 경로

- 방문 신청: 주민등록상 거주지 읍·면·동 행정복지센터
- 온라인 신청: 복지로 홈페이지
- 직권 신청: 담당 공무원이 대상자의 동의를 받아 신청

본인이 신청하기 어려우면 위임받은 주민등록표상 세대원 또는 친족이 대리 신청할 수 있다.

## 자동 신청과 재신청

전년도 지원 기간 이후 정보 변동이 없고 올해도 자격을 충족하면 자동 신청될 수 있다. 이사, 세대원 수 변경, 수급자 변경, 에너지원 변경 등 정보가 바뀌었다면 행정복지센터에 알리고 신규 신청 또는 재신청해야 한다.

## 문의

- 에너지바우처 통합 상담센터: 1600-3190
- 거주지 읍·면·동 행정복지센터

## 신청인과 대리인

- 신청 대상자 본인이 신청할 수 있다.
- 주민등록표 등본상의 세대원 또는 친족이 위임받아 신청할 수 있다.
- 거동이 불편하거나 직접 신청하기 어려우면 담당 공무원이 동의를 받아 직권 신청할 수 있다.
- 독거노인생활관리사, 요양보호사, 장애인활동지원사 등에게 신청 도움을 요청할 수 있다.

## 신청 절차

1. 기초생활수급 자격과 세대원 특성 기준을 확인한다.
2. 거주지 행정복지센터 또는 복지로에서 신청한다.
3. 요금 차감에 사용할 에너지원과 고객번호를 제출한다.
4. 시·군·구가 행복이음 등을 통해 자격을 심사한다.
5. 선정 결과와 지원 금액을 통보받는다.
6. 선택한 방식으로 요금 차감 또는 국민행복카드를 사용한다.

## 서비스에서 확인할 신청 상태

| 상태 | 설명 |
|---|---|
| NOT_APPLIED | 아직 신청하지 않음 |
| APPLIED | 신청 접수됨 |
| UNDER_REVIEW | 자격 심사 중 |
| APPROVED | 지원 대상으로 선정됨 |
| REJECTED | 미선정됨 |
| REAPPLICATION_REQUIRED | 정보 변경으로 재신청 필요 |

## 재신청이 필요한 대표 상황

- 이사하여 주소 또는 에너지 공급사가 바뀜
- 주민등록표상 세대원 수가 달라짐
- 수급자 또는 세대원 특성 정보가 바뀜
- 요금 차감 대상 에너지원이나 고객번호가 바뀜

## 서비스 입력 항목 예시

| 항목 | 설명 |
|---|---|
| address | 주민등록상 주소 |
| applicationStatus | 현재 신청 상태 |
| previousRecipient | 전년도 지원 여부 |
| householdChanged | 세대원 변동 여부 |
| addressChanged | 이사 여부 |
| energyProviderChanged | 에너지 공급사 변경 여부 |
| applicantType | 본인·대리인·직권 신청 |

## RAG 검색 키워드 및 주의사항

검색 키워드: 에너지바우처 신청, 복지로 신청, 행정복지센터, 대리 신청, 직권 신청, 자동 신청, 재신청, 신청기간.

신청 접수와 최종 선정은 구분해서 안내한다. 신청했다는 사실만으로 지원 대상이 확정된 것은 아니다.
