# 에너지바우처 필요 서류

## 기본 서류

- 에너지이용권 발급 신청서: 읍·면사무소 또는 동 행정복지센터에서 작성

## 대리 신청

- 대상자 또는 수급자의 위임장
- 대리인의 신분증

## 요금 차감 신청

- 가장 최근에 납부한 전기, 도시가스 또는 지역난방 요금고지서나 영수증
- 아파트 거주자는 관리비 고지서

신청인의 상황과 지자체 확인 절차에 따라 추가 서류를 요청할 수 있으므로 방문 전에 관할 행정복지센터에 확인한다.

## 서류별 용도

| 서류 | 확인 목적 |
|---|---|
| 에너지이용권 발급 신청서 | 신청 의사와 기본정보 확인 |
| 위임장 | 대리 신청 권한 확인 |
| 대리인 신분증 | 대리인 본인 확인 |
| 전기·가스·지역난방 고지서 | 공급사, 고객번호, 요금 차감 대상 확인 |
| 아파트 관리비 고지서 | 관리비에 포함된 에너지요금과 고객정보 확인 |

## 방문 전 확인사항

- 고지서가 가장 최근 납부분인지 확인한다.
- 고객번호와 실제 거주 주소가 일치하는지 확인한다.
- 고지서 명의자가 신청 대상자와 다르면 관계 확인이 필요한지 문의한다.
- 이사 직후라면 새 주소의 고객번호가 발급됐는지 확인한다.
- 사본이나 휴대전화 사진 제출 가능 여부는 접수기관에 문의한다.

## 서비스 판단 및 입력 항목

| 항목 | 설명 |
|---|---|
| proxyApplication | 대리 신청 여부 |
| authorizationForm | 위임장 준비 여부 |
| proxyId | 대리인 신분증 준비 여부 |
| discountBilling | 요금 차감 신청 여부 |
| latestBill | 최근 고지서 준비 여부 |
| apartmentResident | 아파트 거주 여부 |
| customerNumber | 에너지 고객번호 확인 여부 |

필요서류가 빠졌다면 자격 미충족으로 판정하지 않고 `NEEDS_REVIEW` 또는 `DOCUMENT_REQUIRED`로 안내한다.

## 간단 확인 로직

1. 본인 신청인지 대리 신청인지 확인한다.
2. 대리 신청이면 위임장과 대리인 신분증을 안내한다.
3. 요금 차감 신청인지 확인한다.
4. 요금 차감이면 해당 에너지원의 최근 고지서를 안내한다.
5. 아파트 거주자는 관리비 고지서를 확인한다.
6. 추가서류 여부는 행정복지센터에 문의하도록 안내한다.

## 사용자 질문 및 검색 키워드

질문 예시: 에너지바우처 서류가 뭐야, 대리 신청할 때 무엇이 필요해, 고지서가 꼭 필요해, 아파트는 어떤 서류를 내야 해.

검색 키워드: 에너지바우처 필요서류, 발급 신청서, 위임장, 대리인 신분증, 전기요금 고지서, 도시가스 고지서, 관리비 고지서, 고객번호.

## 주의사항

복지 자격은 행정정보로 조회될 수 있지만 모든 서류가 자동 면제되는 것은 아니다. 접수기관이 추가 증빙을 요구할 수 있다.
