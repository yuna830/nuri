# 리콜제품 발견 시 조치

## 즉시 할 일

1. 공식 리콜 공고에 사용 중지 지시가 있으면 즉시 사용을 멈춘다.
2. 전기·가스·배터리 제품은 안전하게 전원이나 연료를 차단하되, 위험하거나 방법을 모르면 직접 조작하지 않는다.
3. 어린이, 고령자, 반려동물이 제품에 접근하지 못하게 한다.
4. 모델번호, 제조번호, 제품 상태와 구입 내역을 사진으로 남긴다.
5. 공고에 적힌 제조사·수입사·판매처로 연락해 수리, 교환, 환불 또는 회수 절차를 확인한다.

## 하지 말아야 할 일

- 리콜 제품을 계속 사용하거나 다른 사람에게 양도·판매하지 않는다.
- 제조사가 안내하지 않은 방식으로 분해하거나 수리하지 않는다.
- 일반 쓰레기로 바로 폐기하지 않는다. 회수 또는 폐기 지침을 먼저 확인한다.

## 사고나 피해가 발생한 경우

화재, 감전, 가스 누출, 부상 등 긴급 위험이 있으면 안전한 곳으로 대피한 뒤 119에 신고한다. 소비자 상담이 필요하면 1372 소비자상담센터를 이용할 수 있다.

리콜별 조치 내용은 서로 다르므로 DB에 저장된 `corrective_action`과 공식 `source_url`을 최우선으로 안내한다.

## 위해 유형별 우선 조치

| 위해 유형 | 우선 조치 |
|---|---|
| 화재·과열 | 사용 중지, 전원 분리, 가연물과 거리 확보 |
| 감전 | 전원 접촉 금지, 안전하게 차단할 수 없으면 전문가 요청 |
| 가스·연료 누출 | 불꽃과 전기 스위치 조작 금지, 환기·대피 후 119 또는 공급사 신고 |
| 배터리 팽창 | 충전과 사용 중지, 압착·천공·분해 금지 |
| 질식·삼킴 | 어린이 접근 차단, 삼킨 경우 즉시 의료기관 또는 119 |
| 낙상·파손 | 탑승·사용 중지, 파손 부위 접촉 금지 |
| 유해물질 | 피부 접촉과 섭취 중지, 노출 시 제품 안내에 따라 세척·진료 |

위 표는 일반적인 안전 행동이다. 공식 리콜 공고의 구체적인 지시가 있으면 해당 지시를 우선한다.

## 교환·환불·수리 준비사항

- 제품명과 모델번호 사진
- 제조번호, 바코드, 제조일자 사진
- 구입 영수증 또는 주문내역
- 구입처와 구입일
- 제품 상태와 결함 사진
- 공식 리콜 공고 주소 또는 리콜 ID
- 제조사 상담 접수번호와 상담 기록

영수증이 없더라도 리콜 조치를 받을 수 있는지는 공고와 제조사 정책에 따라 다르므로 먼저 문의한다.

## 폐기와 회수

- 제조사가 방문 회수 또는 택배 회수를 제공하는지 확인한다.
- 배터리, 전기제품, 화학제품은 일반 생활폐기물로 버리지 않는다.
- 제품을 보내기 전에 개인정보가 저장된 기기는 공식 안내에 따라 백업·초기화한다.
- 임의 폐기하면 교환이나 환불 증빙이 어려워질 수 있다.

## 서비스 응답 구성

| 필드 | 내용 |
|---|---|
| recallStatus | MATCHED·NOT_MATCHED·NEEDS_REVIEW |
| immediateAction | 즉시 사용 중지 등 우선 행동 |
| hazardType | 화재·감전·질식 등 위해 유형 |
| correctiveAction | 수리·교환·환불·회수 방식 |
| contact | 제조사·수입사 문의처 |
| sourceUrl | 공식 리콜 공고 |
| emergencyGuide | 긴급상황 신고 안내 |

## 서비스 입력 항목 예시

| 항목 | 설명 |
|---|---|
| recallId | 정확 일치한 리콜 공고 ID |
| matchStatus | 리콜 일치 판정 상태 |
| hazardType | 공고에 기재된 위해 유형 |
| productInUse | 현재 사용 중인지 여부 |
| incidentOccurred | 사고 또는 피해 발생 여부 |
| injuryOccurred | 부상 발생 여부 |
| powerConnected | 전원 연결 여부 |
| purchaseEvidence | 영수증·주문내역 보유 여부 |
| correctiveAction | 공식 수리·교환·환불·회수 방법 |
| manufacturerContact | 제조사 또는 수입사 연락처 |

## 안내 로직

1. DB의 정확 일치 결과가 `MATCHED`인지 확인한다.
2. 공식 공고의 위해 유형과 즉시 조치 문구를 가져온다.
3. 사용 중지 여부를 응답 첫 부분에 명확히 표시한다.
4. 공식 수리·교환·환불·회수 방법을 안내한다.
5. 제조사 연락처와 공고 URL을 함께 제공한다.
6. 사고가 발생했다면 119, 의료기관, 1372 등 상황에 맞는 연락처를 안내한다.
7. 정보가 불충분하면 리콜을 확정하지 말고 추가 식별값을 요청한다.

## 사용자 질문 예시

- 리콜 제품이면 지금 바로 뭘 해야 해?
- 계속 사용해도 돼?
- 어디에서 교환받아?
- 영수증이 없어도 환불할 수 있어?
- 리콜 제품을 그냥 버려도 돼?
- 배터리가 부풀었는데 어떻게 해야 해?
- 제조사와 연락이 안 되면 어디에 문의해?

## 관련 문서 및 RAG 검색 키워드

관련 문서: 리콜제품 확인 방법, KC 인증 확인 방법, 안전인증 미확인제품 대응, 전기·가스 사고 대응.

검색 키워드: 리콜 사용 중지, 리콜 제품 교환, 무상수리, 환불, 제품 회수, 리콜 폐기, 화재 위험 제품, 배터리 팽창, 1372 소비자상담센터.

## 주의사항

모든 리콜이 동일한 조치를 제공하는 것은 아니다. 무조건 환불된다고 안내하지 말고 개별 공고의 `corrective_action`을 그대로 우선한다. 긴급 위험이 있으면 고객센터 문의보다 대피와 119 신고가 먼저다.
