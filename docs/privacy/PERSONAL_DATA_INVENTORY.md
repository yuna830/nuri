# 개인정보 처리 목록

> 문서 상태: 포트폴리오 및 설계 검토용 초안  
> 최종 검토일: 2026-07-29  
> 적용 대상: `woori_link`, `ai_backend`, `document_ai_backend`, 고령자·보호자 앱 및 연동 장치

이 문서는 WOORI 서비스가 처리할 수 있는 개인정보와 처리 흐름을 한곳에서 확인하기 위한 설계 문서입니다. 실제 기관 도입 또는 상용 운영 전에는 개인정보 보호책임자와 법률·보안 전문가의 검토를 거쳐 처리 근거, 동의 방식, 보관기간 및 파기 절차를 확정해야 합니다.

## 처리 원칙

- 서비스 제공에 필요한 최소한의 개인정보만 수집합니다.
- 필수정보와 선택정보를 구분하고, 건강·장애 및 위치정보 등은 별도 동의 대상으로 관리합니다.
- AI 분석 결과는 복지 수급, 의료 또는 안전에 관한 최종 결정이 아닌 판단 보조 정보로 사용합니다.
- 외부 AI에는 업무 수행에 필요한 최소 항목만 전송하고, 직접 식별자는 가능한 한 제거하거나 대체합니다.
- 보호자와 복지사는 역할뿐 아니라 해당 어르신과의 연결 관계 또는 담당자 배정을 API에서 확인합니다.
- 정보주체의 열람·정정·삭제·처리정지 및 AI 결과에 대한 사람의 재검토 요청 절차를 제공합니다.

## 역할별 접근 범위

| 역할 | 허용 범위 | 반드시 확인할 조건 |
|---|---|---|
| 어르신 | 본인 정보와 본인 서비스 기록 | 인증된 사용자 ID와 대상자 ID 일치 |
| 보호자 | 연결에 동의한 어르신의 허용된 정보 | 활성 보호 관계, 공개 범위, 관계 해제 여부 |
| 복지사 | 담당자로 배정된 어르신의 업무상 필요한 정보 | 담당자 배정, 기관 범위, 처리 목적 |
| 관리자 | 운영·보안에 필요한 최소 범위 | 관리자 권한, 접근 사유, 감사 로그 |
| AI 서비스 | 해당 작업에 필요한 최소 데이터 | 목적 제한, 비식별화, 결과 검증과 사람의 최종 판단 |

## AI 결과에 적용할 공통 원칙

1. AI 결과임을 화면에 명시합니다.
2. 사용한 주요 데이터와 판단 근거, 기준 시각을 표시합니다.
3. 근거가 부족하거나 서로 충돌하면 확정 답변을 하지 않습니다.
4. 복지 자격, 의료 상태 및 긴급조치를 AI가 단독으로 확정하지 않습니다.
5. 이용자가 오류를 신고하거나 복지사의 재검토를 요청할 수 있게 합니다.
6. 복지사의 승인·수정·후속조치 이력을 남깁니다.

## 구현 전 확정이 필요한 항목

- 개인정보 항목별 정확한 처리 근거와 동의 문구
- 민감정보 및 위치정보의 별도 동의 방식
- 항목별 보관기간과 자동 파기 주기
- 회원 탈퇴 및 보호 관계 해제 시 원본·백업·벡터 DB 삭제 범위
- 외부 AI 서비스별 국외 이전, 보관 및 모델 학습 사용 여부
- 감사 로그의 열람 권한과 보관기간
- 기관 도입 시 개인정보 영향평가 및 위탁계약 필요 여부
- 정보주체의 AI 설명 요구, 이의제기 및 사람 재검토 요청 절차
